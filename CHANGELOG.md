# Changelog

All notable architecture, catalogue, translation, and publication changes are documented here.

## 1.0.0 — 2026-08-25

- Rebuilt the hub as a portable Astro static site with Bulgarian and English routes.
- Migrated all 180 legacy catalogue records into canonical per-record files.
- Added separate locale records and honest source-language fallback.
- Added deterministic JSON and CSV exports, structured status calculation, filtering, detail pages, metadata, and accessibility controls.
- Added responsible source monitoring, evidence proposals, compact state architecture, CI, draft-PR workflow, and publication bundles.
- Preserved `/rare_disease_education_hub`, `/rare_disease_education_catalog.json`, and `/rare_disease_education_catalog.csv`.
- Added automated unit, integration, browser, crawler, and accessibility checks.
- No deployment was performed.
