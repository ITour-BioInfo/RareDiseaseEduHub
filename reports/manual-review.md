# Manual review queue

These concerns were known before migration and must not be changed without current official-source evidence.

- Clinical Development record linking to a Preclinical Development page.
- Duplicate composite-endpoints webinar records.
- REMEDi4ALL application status.
- ECMGG examination lifecycle and next registration opening.
- University of Glasgow versus University of Leeds identifier metadata.
- ASHG search URL versus direct course URL.
- Application windows represented as event dates.
- Arrival dates represented as teaching dates.
- Recording availability represented as a live-event period.
- Recurring series sorted by a historical first occurrence.
- Date-TBA programmes labelled as upcoming.
- Resources labelled past when they are merely not currently running.
- Source conflicts for NHS course deadlines.
- Source conflicts for Covering the Gaps dates.

Each resolution must name the record, field, old and proposed values, direct official URL, short evidence excerpt, confidence, and reviewer decision.
